# RealityCheck Governance Changelog

## rc-gov-0.2 — Authoritative payload for RC-WC-001

- Established the two-axis result model as the governance baseline.
- Clarified that Claim IDs govern analytical conclusions, risk assessments, material limitations, and decision-relevant recommendations; ordinary UI copy is outside this requirement.
- Established default deny for unknown or unsupported analytical claims.
- Established safe fallback as an INCONCLUSIVE governed result, not a free-form message.
- Clarified that analysis failure must never degrade into NO_SIGNAL, authentic, or safe.
- Clarified that T-C is a mandatory production evaluation tier but not an assumption applied to every MINI App input file.
- Kept statistical detector thresholds and numeric deployment criteria outside RC-WC-001; they remain PROPOSED until separately ratified.
